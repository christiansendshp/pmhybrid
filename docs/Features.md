# Features

## Operational summary

- Verified capabilities: 25
- Latest verification: `2026-09-15` — lint, build, unit, e2e green (103 api e2e, 33 api unit, 105 web)
- Known limitations: no refresh-token revocation (ADR-005); Roadmap `Depends on` not reconciled into `TaskDependency`; PM Hub's own write-back Agentslog entries are ingested only after an external file change; a status write-back for a Near term row adds a duplicate Active row (GAP-19); Workload's filter bar calls `GET /projects` to list the user's projects, which recomputes each project's full progress rollup just to populate a dropdown — fine at demo scale, worth a dedicated lightweight endpoint before real data; `ProjectContext` is DI-scoped to `ProjectDashboard`'s routed children (kanban/progress/conflicts/settings/...) and throws if one is ever routed outside that parent; `prisma/seed.ts`'s role-permission upsert only adds, never removes — a `prisma db seed` reseed silently re-grants any permission an admin had stripped from a system role via `PATCH /roles/:id/permissions`
